Misprinter (Lovely-only)
Install the Misprinter folder into %AppData%\\Balatro\\Mods.

Expected structure:
Mods/
└── Misprinter/
    ├── lovely.toml
    └── main.lua
Restart Balatro after installing. Check %AppData%\\Balatro\\Mods\\lovely\\log
and %AppData%\\Balatro\\Mods\\lovely\\dump if the preview does not appear.

This initial HUD reads G.deck.cards[1]; it does not move or draw cards.
