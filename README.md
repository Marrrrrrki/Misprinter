
# Misprinter

**Misprinter** is a lightweight Balatro HUD mod that previews the next five cards in your draw pile using their in-game card artwork.

## Features

- Displays up to the next **5 cards** from the draw pile.
- Uses the original Balatro card artwork.
- Shows a compact preview panel in the top-right corner.
- Does not move, draw, discard, or modify cards.

## Requirements

- Balatro
- [Lovely](https://thunderstore.io/c/balatro/p/Thunderstore/lovely/)

Lovely is the only mod dependency. Misprinter does not require Steamodded.

## Installation

### r2modman

Install Misprinter through the Balatro community in Thunderstore or r2modman once published. Make sure Lovely is enabled.

### Manual installation

1. Install Lovely.
2. Put the Misprinter folder in `%AppData%/Balatro/Mods`.
3. Make sure the folder contains `lovely.toml` and `main.lua`.
4. Launch Balatro.

## Troubleshooting

Check Lovely's log and dump folders if the preview doesn't appear:

- `%AppData%/Balatro/Mods/lovely/log`
- `%AppData%/Balatro/Mods/lovely/dump`
